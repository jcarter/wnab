# WNAB Agent Instructions

## Verification

- Run `npm run test:run` and `npm run build` after implementation changes.
- Review visible frontend changes using Chrome DevTools MCP.
- Verify desktop and mobile viewports and both light and dark themes.
- Check console issues and errors, along with failed network requests.
- Do not expose real financial data in screenshots or browser artifacts.
- Report exactly which pages, viewports, interactions, and checks were verified.
